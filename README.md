# RevKeen browser packages

Release mirror for RevKeen's browser packages. The source lives in RevKeen's
main repository; this repository is updated only by a reviewed release pull
request, and merging one publishes to npm with provenance.

| Package | What it is |
| --- | --- |
| [`@revkeen/js`](https://www.npmjs.com/package/@revkeen/js) | Browser client for carts and storefront products, using a publishable key (`rk_pk_…`) |
| [`@revkeen/react`](https://www.npmjs.com/package/@revkeen/react) | React hooks and components for selling RevKeen products, built on `@revkeen/js` |
| [`@revkeen/checkout-embed`](https://www.npmjs.com/package/@revkeen/checkout-embed) | Loader for the hosted RevKeen checkout embed |

For server code and secret keys, use
[`@revkeen/sdk`](https://github.com/RevKeen/sdk-typescript).

Please report issues to support@revkeen.com. Pull requests here are not
accepted; changes are made in the main repository and released through this
mirror.
